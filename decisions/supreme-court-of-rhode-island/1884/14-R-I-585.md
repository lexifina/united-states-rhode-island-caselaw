# Friedburg v. Knight

## Majority (Pee, CuEIAM.)

Pee, CuEIAM.
We think the replications are bad. If the plaintiff wishes to set up fraud as an answer to the pleas of a release and an acquittance, he ought to set forth the acts by which the alleged fraud was perpetrated, so that the court can judge whether they amount to fraud or not, and, if they amount to fraud, so that the defendant can know definitely what he is to take issue upon. See cases cited for defendants.
Demurrer sustained.
